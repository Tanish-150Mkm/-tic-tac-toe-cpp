# Tic Tac Toe in C++

A two-player Tic Tac Toe game that runs in the terminal, built as my first C++ project.

## How to play
- Two players take turns on the same keyboard
- Enter row and column (1-3) to place your mark
- First to get 3 in a row wins
- Supports play again without restarting

## How to run
g++ tic-tac-toe-game.cpp -o tictactoe
./tictactoe
